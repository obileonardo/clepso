# Protocol email artwork

The founder selected Protocol and approved the Clepso logo blended into the dithered hero. The approved logo footprint was enlarged from 800 × 201 to 1000 × 251 pixels (1.25× width; height rounded to the nearest pixel) without enlarging the whole image. The final email export is 1200 × 474, under 500 KB.

The background derives from [React Email’s Protocol artwork](https://github.com/resend/react-email/blob/e0561e164e9c28859d24373804e30b364931ee77/apps/demo/emails/static/dither/dither-image-1.png). Its MIT notice is retained in LICENSE-react-email.txt. Clepso’s name and mark remain covered by the repository’s TRADEMARKS.md.

The approved blend was prepared with the built-in image editor; the exact logo-layer enlargement and PNG export used founder-authorized Pillow compositing. The image is flattened so mail clients need no background-image or overlay support. Keep the v1 URL available for emails already sent. Use a new filename for future artwork revisions.

## Display headings

The four `clepso-heading-*-v1.png` files are generated by `scripts/build-email.py`, using only the Python standard
library and the same `design/brand/pipeline/pixel_glyphs.py` grid and kerning as Clepso Pixel. Each grid pixel is
eight raster pixels, displayed at half size (40 px font size, 50 px line height). Long headings wrap at a maximum
516 CSS pixels. Opaque ink backgrounds preserve the white lettering in email clients that recolor surrounding
HTML. These are deterministic font renders, not AI approximations. Regenerate with the HTML; `--check` verifies
the exact PNG bytes. No Pillow, system font registration or remote font loading is required.

Headings have full alt text and an accessible `h1` name. Body copy and actions remain real HTML text. This
avoids the Courier substitution reported in the founder's inbox; web font support is not a delivery guarantee.
Retain these versioned URLs for sent emails; use a new version if the glyphs, wording or rasterizer change.
