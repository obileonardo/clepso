Principles

What every component has to guarantee, whatever it looks like.

A number always says where it came fromEvery value shows its source and how old it is. Components take provenance-carrying values; there is no bare-number input.
Missing is never zeroAbsent, null, stale and not connected are four different states with their own words. None of them can render as 0%.
Never colour aloneEach state has a symbol, words, a bar pattern and a spoken phrase. Greyscale and VoiceOver users get the same meaning.
Restyle without changing meaningPalette, spacing and layouts can change freely. State names, labels and accessibility text are locked and tested.

Components

The first six components (PRD §25.2), each in every state the engine can produce.

ProviderCard

One provider: identity, plan, one row per allowance pool, the active session. Compact in the menu bar popover, expanded in provider detail.

QuotaProgress

One allowance pool. Takes a provenance-carrying value, never a bare number, so missing data cannot render as 0%. Every state has its own symbol, words and bar pattern as well as colour.

ResetCountdown

Counts down from a verified reset instant. At the reset time it says “Reset expected”, never “Ready”: only a fresh reading can say that.

PlanPill

The plan label always carries how it is known. The plan never feeds any arithmetic.

ConnectionHealth

Whether readings are arriving, with the age of the last one. Never “100% connected”.

DataSourceLabel

Source and freshness, on every value. Freshness is never omitted; stale values say “last seen”.
