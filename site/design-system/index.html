Phosphor

The pixel layer (increment 1.7). Inspired by the Matrix, the Tesla Roadster's interface, Hearth's glass and a pixel UI pack used only as a style reference; every shape is drawn in code on a pixel grid, so it stays sharp and scales with text size. Dark in both appearances.

PixelLimitRow

One allowance pool in the pixel style. Same status words, freshness, reset line and VoiceOver sentence as QuotaProgress (tested); the optional pace line always says “Estimate”.

PixelBar

The segmented bar. Stale values are dithered and missing values draw only an outline, so meaning never rests on colour.

PixelButtonStyle

Bevelled pixel buttons: a lit top edge and a shaded bottom edge that swap when pressed.

PixelTabs

Tabs in the pixel-pack manner, used in the Details window and Stats.

PixelStat

A value over a small pixel caption, for the session strip and Stats.

PixelLineChart

History drawn as steps snapped to a pixel grid, with dotted 80/95/100 guides, NOW, and the dashed pace projection. VoiceOver reads a sentence instead of the drawing.

PixelHeatmap

Activity like Claude Code's /stats: one column per week, Monday on top, four levels plus empty.

PixelPanel

The frame every pixel screen sits in: stepped corners, an outer frame and an inner rule; glass behind it in the app.

Principles

What every component has to guarantee, whatever it looks like.

A number always says where it came fromEvery value shows its source and how old it is. Components take provenance-carrying values; there is no bare-number input.
Missing is never zeroAbsent, null, stale and not connected are four different states with their own words. None of them can render as 0%.
Never colour aloneEach state has a symbol, words, a bar pattern and a spoken phrase. Greyscale and VoiceOver users get the same meaning.
Restyle without changing meaningPalette, spacing and layouts can change freely. State names, labels and accessibility text are locked and tested.

Classic components

The first six components (PRD §25.2) in the classic system theme, each in every state the engine can produce. Still in the code; the pixel components reuse their wording and accessibility text.

ProviderCard

One provider: identity, plan, one row per allowance pool, the active session. Compact in the menu bar popover, expanded in provider detail.

QuotaProgress

One allowance pool. Takes a provenance-carrying value, never a bare number, so missing data cannot render as 0%. Every state has its own symbol, words and bar pattern as well as colour.

ResetCountdown

Counts down from a verified reset instant. At the reset time it says “Reset expected”, never “Ready”: only a fresh reading can say that.

PlanPill

The plan label always carries how it is known. The plan never feeds any arithmetic.

ConnectionHealth

Whether readings are arriving, with the age of the last one. Never “100% connected”.

DataSourceLabel

Source and freshness, on every value. Freshness is never omitted; stale values say “last seen”.
