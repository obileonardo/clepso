    CLEPSO

    Your coding-agent limits, //before you hit them.

    A macOS menu bar app that shows how much of your Claude Code and Codex limits you have used, when they reset and how fast you are going, from what those agents report on your own Mac. These pages document how it is built, what every number means and where the work stands.

    Limit state, with hysteresis

    Available

    // Sources/UsageEngine/PoolReducer.swift
static func classify(_ used: Decimal, previous: LimitState, config: EngineConfig) -> LimitState {
    if used >= config.exhausted { return .exhausted }
    if used >= config.critical { return .approaching(.critical) }
    if previous == .approaching(.critical), used > config.critical - config.hysteresis { return .approaching(.critical) }
    if used >= config.warning { return .approaching(.warning) }
    if case .approaching = previous, used > config.warning - config.hysteresis { return .approaching(.warning) }
    return .available
    05 / HOW IT READS

    A reading's path

    From Claude Code's status line to the menu bar, all on your Mac. The sixth layer runs only if you sign in.

    1. 01
      Claude Code · Status lineRuns your status line command on every refresh and hands it a JSON description of the session.
    2. 02
      Helper · statusline.sh · clepso-statuslinePasses the input to your own status line unchanged, keeps only allowlisted fields, sends them on.
    3. 03
      Ingest · Socket · IngestorLocal socket, peer checks and a rate limit; each frame becomes readings with source and freshness.
    4. 04
      Store · SQLite · UsageEngineOne transaction per frame: insert the reading, work out each limit's state, keep the history.
    5. 05
      Show · Menu bar · DashboardRenders snapshots it is handed and never computes a state itself.
    6. 06
      Sync · Optional, if you sign inUploads daily counts once an hour; the only module allowed to use the network.
