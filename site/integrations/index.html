    Within reach

    Available from 0.4.0 alpha 1. Each connection starts with your choice in Clepso Settings.

    On this page
    • 01 Desktop widgets
    • 02 Ask an assistant
    • 03 Updates in the app
    • 04 Small, deliberate boundaries

    Desktop widgets

    In Settings → Integrations, enable Desktop widgets. Add Clepso limits from the Mac widget gallery. The small layout shows two windows; the medium layout shows four. Automatic readings come first. Manual entries, missing values, old readings and expected resets stay labeled. Click the widget to open Limits.

    macOS controls refresh frequency. A widget is a recent snapshot, not a live menu-bar replacement. Turning sharing off removes its shared snapshot. No account is required.

    Ask an assistant

    In Settings → Integrations, enter a client name, review the disclosure and choose Allow. Copy setup and add the JSON to that client's documented MCP configuration. Clepso never edits another client's settings automatically.

    ToolReturns
    get_limitsReported used percentages, reset times, source and freshness
    get_reader_healthObservation times and whether the app snapshot/readings are current

    Both tools accept an optional provider filter. Missing data stays missing; an expected reset never proves availability. The server uses local stdio, with no shell, file, credential, settings or database tool.

    Your client may forward usage readings to its AI service. Local processes running as your Mac user can read the shared file. Revoke any client in Settings; running clients lose permission on their next request. Deleting local data revokes all grants. Demo data is never shared.

    Updates in the app

    Use Settings → Updates to check manually, enable daily checks, or allow automatic installation. Automatic options start off. This alpha channel includes preview releases. Sparkle verifies signed feeds and archives before extraction; official app and DMG releases remain signed and notarized. No system profile is sent.

    The first updater-enabled release must be installed using the DMG or Homebrew once. Homebrew remains available: brew upgrade --cask --greedy obileonardo/clepso/clepso.

    Small, deliberate boundaries

    Widgets and MCP receive only provider/window labels, usage percentages, observation/reset times, source and state. They never receive prompts, replies, paths, session identifiers, email addresses or credentials. Read the privacy notice for account uploads and service providers.
