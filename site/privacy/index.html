Privacy

Pulse works fully on your Mac without an account. If you choose to sign in, it uploads daily counts so you can see your goals and usage elsewhere. This page lists every field. Draft, 17 October 2026.

On your Mac

Pulse reads Claude Code's status line (limits, model, context, session cost estimate, durations, lines changed), and, only if you turn them on, Claude Code's statistics file and four background hooks that count subagents per task. A helper drops everything else (prompts, replies, file paths, project names) before anything reaches the app. Readings stay in a local database for 90 days (sessions and tasks 30). Delete all removes everything Pulse stored and restores Claude Code's settings.

If you sign in: what is uploaded

Once an hour, the last 14 days, to a database in Frankfurt (Supabase, EU), readable only with your sign-in:

ProfileName you typed, plan name you choseAlways

Never uploaded: prompts, replies, file or folder paths, project or repository names, transcript locations, session or agent ids, per-session cost, your Claude account details or anything about other apps.

Your account

Sign-in is by email link (Apple, Google and GitHub to follow). Your email is held by the sign-in service to send links; it is not stored with your counts. Delete account (Pulse › Account) deletes the account and every row stored with it, at once. Signing out stops uploads; deleting the account removes what was uploaded. Nothing is sold or shared, and there is no advertising or tracking.

Security

Every table is protected by row-level security: a signed-in user can read and write only their own rows, and an anonymous request is refused. The app holds only the project's publishable key; your session is kept in this Mac's Keychain.
