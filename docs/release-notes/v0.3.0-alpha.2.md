# Clepso 0.3.0 alpha 2

A small interface update for the Mac app, accompanied by a refreshed website.

- Toggle thumbs now follow the track’s stepped pixel corners in both On and Off states.
- Account uploads use a compact status/action layout. The full privacy explanation remains available under “What gets uploaded?”
- Connected accounts show connection wording rather than asking you to sign in again.
- The website has a clearer product landing page and a new interactive character-art preview. The preview’s new characters are not in this Mac binary yet.

The existing Claude desktop/IDE connection, Codex reading, Calendar export and optional email accounts remain available.
This update does not install new agent integrations or change your existing consent choices.

## Install

Apple silicon Mac, macOS 14 or later. Quit Clepso, replace the existing app using the signed, notarized DMG, then reopen it.
Existing settings and usage history are retained. Homebrew users can upgrade the named Clepso cask after the tap update.

This is an alpha. Automatic updates are not enabled. Full VoiceOver, older/clean macOS, and long-sleep/restart notification
behavior remain additional QA work. The shipped desktop/IDE bridge depends on the provider continuing to expose its reviewed usage fields.
