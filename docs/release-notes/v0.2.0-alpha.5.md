## Clepso 0.2.0 alpha 5: Goals controls

Goals now use Clepso's existing pixel minus/plus buttons instead of native up/down chevrons. Each target card keeps
the Target label and value on the left, with the On/Off toggle and adjustment buttons aligned to the right.
Active-day targets still range from 1–7 in single-day steps; percentage targets range from 10–100 in five-point
steps. Buttons disable at the bounds. Turning a target off hides its adjusters, and turning it on restores its
default. Each adjustment button has a descriptive accessibility label and uses the existing pixel focus style.

Native QA verified all three target ranges, saved changes and toggle behavior, plus the layout in dark and light
appearances. Existing usage history, goals, menu-bar preferences and source connections are preserved.

Release packaging now checks free space on the actual build volume and separately on the temporary volume,
so builds stored on an external drive use the correct storage requirements.

Download `Clepso-0.2.0-alpha.5.dmg` below. Requires **macOS 14+ on Apple silicon**. The app and disk image are Developer
ID signed, Apple notarized and stapled. Quit Clepso before replacing the installed app, then reopen it.
`SHA256SUMS` contains the disk-image checksum. Public Stage A feature gates remain in effect.
