# Clepso 0.4.0 alpha 2 — recorded activity

Gemini CLI users can enable Read recorded token activity in Settings. Limits shows numeric activity from the newest 16 retained recordings on this Mac. Numeric activity, hashed deduplication keys and a temporary file cache stay in memory. Disabling clears the cache.
