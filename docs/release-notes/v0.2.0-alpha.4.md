## Clepso 0.2.0 alpha 4: A colored, compact menu pill

The menu pill now uses Clepso's theme accent, uppercase labels and the bundled Clepso Pixel display face.
Horizontal content padding is 6 points per side, reduced by 2 layout pixels from the former 8-point inset.
The icon and text stay centered as the Claude/Codex 5-hour and 7-day readings rotate. Approaching limits use
amber, reached limits coral, and old/missing readings keep their explicit wording and state glyphs.

Editing a manual reading now shows an update heading. Native QA covers keyboard focus, Tab/Shift-Tab,
Space/Return/Escape, Calendar-grid arrows, manual form validation/save/edit/provider-plan clearing, and importing
a synthetic weekly reset into macOS Calendar. Test data is removed afterward. Calendar actions remain hidden
in this public Stage A build. Accounts, automatic updates and the optional desktop/IDE mod remain off.

Download `Clepso-0.2.0-alpha.4.dmg` below. Requires **macOS 14+ on Apple silicon**. The app and DMG are Developer ID
signed, Apple notarized and stapled. Quit Clepso before replacing your installed copy, then reopen it.
Usage history and preferences are preserved. `SHA256SUMS` contains the disk-image checksum.

Intel builds and a separate clean macOS user-account test remain outstanding. This is an alpha release.
