## Clepso 0.2.0 alpha 3: Centered menu bar readouts

The dynamic menu bar's icon and text are now centered together inside the pill. Alpha 2 reserved room for the
longest reading but left all unused space on the right, making shorter frames look off-center. The corrected
drawing distributes that space on both sides, on whole pixels, while preserving the same width across rotation.

All [alpha 2 features](https://github.com/obileonardo/clepso/releases/tag/v0.2.0-alpha.2) remain: Claude Code and Codex
5-hour/7-day readouts, pinned modes, explicit stale/reset states and accessibility pause controls. Settings and
usage history are preserved. This build keeps accounts, automatic updates and the optional desktop/IDE mod off.

Download `Clepso-0.2.0-alpha.3.dmg` below. Requires **macOS 14+ on Apple silicon**. Quit Clepso, open the DMG, replace
your installed app, then reopen it. The app and DMG are Developer ID signed, Apple notarized and stapled.
`SHA256SUMS` contains the disk-image checksum. The alpha 2 platform/verification limitations still apply.
