# Clepso 0.3.0 alpha 1 — Claude, everywhere

This update includes the tested desktop/IDE connection, weekly Calendar export and clearer Goals controls in the
installed app. Apple silicon, macOS 14 or later. This remains alpha software.

## Included

- **Claude desktop and VS Code limits.** Settings → Claude Code → **Desktop app and VS Code panel** is now
  available. Its consent sheet installs Clepso's small, reversible Claude Code mod. It reports five-hour and weekly
  usage, reset times, context usage and model identity after replies in the desktop **Code tab** and the graphical
  VS Code panel. Terminal tracking continues through the existing status line. Readings share the same limits;
  they are not added together. A fresh terminal source has priority for 60 seconds.
- **Clear Goals buttons.** Dedicated pixel plus/minus icons replace font characters, with a centered, balanced cross.
  Right-aligned controls, target toggles, value bounds and accessible button names are preserved.
- **Add reset to Calendar.** A reported weekly reset on Limits can open a one-time Calendar event. Calendar asks
  before adding it. A reset is an expected time reported by the provider and can change; an imported event does
  not update automatically. Five-hour resets are excluded.
- **Optional email accounts.** The official build includes the existing accounts project and branded Protocol
  sign-in emails. Sign in explicitly from Account to sync daily activity summaries to Clepso's hosted web dashboard.
  Sign-in uses a one-time link and PKCE; open it on the Mac that requested it. Apple/Google/GitHub console setup
  remains separate and those providers are not enabled. Local tracking works without signing in.
- **What's new.** Existing users upgrading from v0.2 see a card linking to the new connection, Calendar and Goals.
  The rotating Claude/Codex menu-bar limits, earlier alignment/color/type improvements, manual snapshots and
  retention/reset-reminder fixes remain included.

## Privacy and verification

The mod hands only allowlisted usage/model/session fields to the fixed local helper; session identifiers are HMAC
references before socket delivery. It reads no prompts, replies, transcripts, code, credentials or project paths.
The mod's data path stays on the Mac. Optional signed-in accounts upload the documented daily aggregates, never
those raw frames; see [privacy and security](../PRIVACY_AND_SECURITY.md#9-optional-accounts-sync).

Live checks on this Mac verified desktop Code 2.1.304 and VS Code extension 2.1.305: real quota/reset frames,
normal mapper/store adoption, native usage agreement, desktop/IDE model-id agreement and matching hook tasks.
Removal and restoration were verified at the settings/files level. Native plugin-removal UI could not be checked
after macOS capture errors. Older/clean macOS, full VoiceOver and long sleep/restart verification remain incomplete.
See the [desktop](../qa/2026-10-21-desktop-mod.md) and [IDE](../qa/2026-10-21-vscode-mod.md) records for their exact scope.

Desktop/IDE installation remains explicit opt-in for every user. It starts with a new Claude session; an
organisation that disables mods cannot supply those readings. This supports Claude Code surfaces, not general
Claude Chat conversations. Missing or stale readings retain their stated condition.

No automatic updater is included. Quit Clepso, replace the app with this DMG's copy, then reopen it; the Homebrew
tap also tracks this release. Existing history and preferences are preserved. A signed, notarized and stapled app
and DMG plus `SHA256SUMS` accompany the release.
