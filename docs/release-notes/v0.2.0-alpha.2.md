## Clepso 0.2.0 alpha 2: Dynamic menu bar

See which agent and window a limit belongs to without opening the panel. The menu bar now rotates through
**Claude Code 5-hour, Claude Code 7-day, Codex 5-hour and Codex 7-day** readings every six seconds. Each frame shows
the agent, window and **percentage used**, with that window's existing Clepso pixel status glyph.

- Most pressing windows lead the rotation; every configured window still gets a turn.
- **Settings → General → Menu bar readout** lets you pin any one window or keep the previous aggregate summary.
  Switch off **Show usage in menu bar** for the icon alone. Choices survive restarting the app.
- Old readings explicitly say **OLD**. A passed reset says **RESET?**, awaiting fresh evidence; elapsed time never
  invents availability. Missing readings say **N/A** or **WAIT**, and a pinned disabled agent says **OFF**.
- The readout reserves a consistent width so neighbouring menu bar items stay in place. Rotation pauses on hover,
  with Reduce Motion and with VoiceOver. The accessible label/help include all four windows and their freshness.
- Codex reading remains opt-in under **Settings → Codex**. Automatic readings still come from Claude Code's status
  line and Codex's local session files; manually entered allowances stay separate.

### Install or update

Requires **macOS 14+ on Apple silicon**. Quit Clepso, download `Clepso-0.2.0-alpha.2.dmg` from Assets below, open it,
and drag **Clepso** into **Applications**, replacing the previous copy. Launch the new copy from Applications.
Your history, connections, goals and preferences are preserved. There are no automatic updates.

The app and DMG are Developer ID signed, notarized by Apple and stapled. `SHA256SUMS` contains the disk-image hash;
with both downloaded files in one folder, run `shasum -a 256 -c SHA256SUMS` to verify it.

### Alpha scope

Everything from [alpha 1](https://github.com/obileonardo/clepso/releases/tag/v0.2.0-alpha.1) remains included.
This is still an alpha build. Accounts, automatic updates and the optional Claude Code desktop/IDE mod remain off
in this public build. It makes no network requests and does not transmit prompts, replies or project paths.
Intel Macs are unsupported. macOS 14/15 and a first launch under a separate clean macOS user account remain
unverified, as does the complete native keyboard/form/Calendar-import flow. See the
[readout specification](https://github.com/obileonardo/clepso/blob/main/docs/specs/dynamic-menubar.md) for state semantics.
