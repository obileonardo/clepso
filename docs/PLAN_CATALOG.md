# Bundled plan catalog

The catalog is local data, versioned independently of its JSON schema. Version 1.1.0 retains all 31 original entries
and adds 13 plan names for manually tracked Cursor and GitHub Copilot accounts. No new entry supplies a quota,
entitlement association or price. Selecting any plan in a manual reading says **Selected · not verified**, regardless
of whether the catalog's plan name itself has an official source.

Names checked 19 October 2026:

- Cursor: Free, Plus, Premium, Super, Ultra, Teams and Enterprise. [Official pricing](https://cursor.com/pricing).
- GitHub Copilot: Free, Pro, Pro+, Max, Business and Enterprise. [Official plans](https://github.com/features/copilot/plans).

Windsurf's pricing URL redirected to Devin's pricing during this check. That does not establish which plan a
Windsurf user holds, so its manual card offers **Not sure** rather than inventing a mapping.

The original seven OpenAI subscription entries retain their unverified status. Catalog metadata never turns API
credits into subscription allowance or verifies a user's account. Remote catalog downloads remain absent from the
network-free alpha; changing the bundled catalog requires a reviewed app update.
